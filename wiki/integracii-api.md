## API-ключи

API доступен только на тарифе «Бизнес». Ключи создаются в разделе «Интеграции» → «API-ключи».

- Полное значение ключа показывается один раз при создании — сохраните его сразу.
- Для каждого ключа задаются права: только чтение или чтение и запись.
- Ключ можно отозвать в любой момент; интеграции, которые им пользовались, сразу перестанут работать.

Ключ передаётся в заголовке запроса. Не размещайте его в коде витрины и в файлах, доступных покупателям. При переходе на тариф «Старт» ключи деактивируются.

## Вебхуки

Вебхук — это HTTP-запрос, который «Прилавок» отправляет на ваш адрес при наступлении события. Адрес указывается в разделе «Интеграции» → «Вебхуки», там же выбираются события:

- заказ создан, статус заказа изменён, заказ отменён;
- платёж ожидает подтверждения, платёж оплачен, оформлен возврат.

Ваш сервер должен ответить кодом 2xx в течение 10 секунд. Тело запроса содержит идентификатор события — используйте его, чтобы не обработать одно событие дважды.

## Повторные попытки

Если доставка вебхука не удалась, «Прилавок» повторяет её 3 раза с интервалами 1, 5 и 30 минут. После этого попытки прекращаются, а событие остаётся в журнале со статусом ошибки — оттуда его можно отправить повторно вручную.

## Журнал

Журнал доставки находится в разделе «Интеграции» → «Журнал». По каждому событию видны время, адрес, код ответа, число попыток и тело запроса. Записи хранятся 30 дней. Там же есть журнал вызовов API с кодами ответов.
